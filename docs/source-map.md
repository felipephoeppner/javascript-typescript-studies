## Preservation approach

- Examples were moved and grouped, not redesigned into an application.
- Separate lesson sections are enclosed in plain JavaScript blocks when their original variables would otherwise collide.
- HTML files are kept alongside their related JavaScript files, and `<script src>` paths were updated accordingly.
- Known incomplete or buggy examples are retained and documented in the root README.
